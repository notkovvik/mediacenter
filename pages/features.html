// features.md

Что уже работает

Каталог

Автоматически подхватывает файлы из указанных папок. Постеры, описания, рейтинги — из открытых источников.

Плеер

Локальное воспроизведение без перекодирования. Запоминает позицию, поддерживает сабы и несколько аудиодорожек.

Поиск

Ищет сразу по всей библиотеке. Можно фильтровать по жанру, году, рейтингу, длительности.

Несколько пользователей

У каждого свои «продолжить смотреть», избранное и история. Регистрации на внешних сервисах не нужны.

Работает по локалке

Поднял на домашнем сервере — смотри с телефона, планшета, ноутбука. Внешний интернет не нужен.
