// install.md

Поставить за пять минут

mediacenter — это один бинарник + папка с твоей медиатекой. Никаких баз данных, никаких докер-композов на 200 строк.

// linux & macos

  1. Скачай последний релиз: curl -L -o mc.tar.gz https://github.com/notkovvik/mediacenter/releases/latest
  2. Распакуй: tar -xzf mc.tar.gz && cd mc
  3. Запусти: ./mediacenter --dir ~/Media
  4. Открой http://localhost:8080 в браузере.

// windows

  1. Скачай mediacenter.exe со страницы релизов
  2. Положи в любую папку, например C:\mediacenter\
  3. Запусти из PowerShell: .\mediacenter.exe --dir D:\Media
  4. Открой http://localhost:8080

Хочешь собрать из исходников?

Клонируй репу, загляни в README.md. Там есть инструкция для Go 1.22+ и Node 20+ (под фронт).

Нужен домен?

По умолчанию mediacenter слушает только 127.0.0.1. Для доступа из локалки запусти с флагом --lan.

// questions.log

Частые вопросы

А онлайн-кинотеатры подключаются?

Нет. Только твои локальные файлы. Это принципиальная позиция.

Сколько весит?

Бинарник — около 12 МБ. Индекс метаданных для библиотеки в 5 ТБ — меньше 200 МБ.

Можно поставить на NAS?

Да. Под arm64 тоже собирается — Synology, QNAP, обычный Raspberry Pi.
